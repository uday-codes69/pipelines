🫀 Heart Disease & Stroke Prediction

A Machine Learning web app built with Streamlit that predicts the risk of heart disease or stroke based on medical parameters.

⸻

🚀 Features
	•	🧠 Uses a trained KNN / Logistic Regression model.
	•	📊 Input fields for medical data (blood pressure, cholesterol, ECG, etc.).
	•	🌐 Deployed with Streamlit for easy interaction.
	•	📈 Shows accuracy and performance metrics of the trained model.

# 🔹 Clone the repository
git clone https://github.com/username/HeartDisease-Predictor.git
cd HeartDisease-Predictor

# 🔹 (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows

# 🔹 Install dependencies
pip install -r requirements.txt

# 🔹 Run the Streamlit app
streamlit run app.py
